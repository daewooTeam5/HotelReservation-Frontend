<h1 align="center">HotelReservation-Frontend</h1>

<p align="center">
  <b>Vue 3와 Vite 기반의 호텔 예약 프론트엔드 서비스</b><br/>
  다양한 사용자(일반, 오너, 관리자)를 위한 통합 호텔 예약 플랫폼
</p>

---

## ✨ 주요 기능

- 🔐 <b>회원가입 및 로그인</b> (소셜 로그인 포함)
- 🏨 <b>호텔 검색 및 상세 정보 조회</b>
- 📅 <b>호텔 예약 및 결제</b>
- 💖 <b>찜(위시리스트) 기능</b>
- 🎟️ <b>쿠폰 및 포인트 관리</b>
- 🧑‍💼 <b>관리자/오너/유저별 맞춤 레이아웃</b>
- 📊 <b>통계 및 리뷰 관리</b>

---

## 📁 폴더 구조 요약
```text
src/
  components/      # UI 컴포넌트
  layout/          # 레이아웃 컴포넌트
  router/          # 라우터 설정
  stores/          # Pinia 스토어
  types/           # 타입 정의
  utils/           # 유틸리티 함수
  views/           # 페이지 뷰
public/            # 정적 파일 및 이미지
```

---

## ⚡️ 설치 및 실행 방법

```bash
# 1. 의존성 설치
npm install

# 2. 개발 서버 실행
npm run dev
```

---

## 🛠️ 사용 기술 스택
| 기술         | 설명                |
| ------------ | ------------------- |
| Vue 3        | 프론트엔드 프레임워크 |
| Vite         | 번들러/개발 서버     |
| TypeScript   | 정적 타입            |
| Pinia        | 상태 관리            |
| Axios        | API 통신             |
| Firebase     | 알림 등              |
| ESLint/Prettier | 코드 스타일 관리   |
